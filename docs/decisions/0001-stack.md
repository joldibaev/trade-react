# ADR-0001. Стек клиента

**Статус:** предложено (ждёт приёмки владельцем) · **Дата:** 2026-10-27

## Контекст

Клиент на Angular (`trade-ng`) заменяется на React — навсегда (решение
владельца). Владелец сам код не пишет, код пишут агенты, поэтому важны: одна
общая реализация каждой повторяющейся вещи, правила в проверках (типы, линтер,
тесты), а не в тексте, и библиотеки, которые агенты хорошо знают. Сервер —
TradeNet; единственный договор — его OpenAPI-документ. Экраны должны работать
на телефоне, планшете и компьютере, на трёх языках: русском, узбекском,
казахском.

### Версии, требующие внимания

- **ESLint 10 и jsx-a11y.** Последний выпуск `eslint-plugin-jsx-a11y` (2024)
  объявляет поддержку ESLint до 9. Его правила не используют убранные в 10-й
  версии функции, а проверка показала, что они срабатывают (картинка без `alt`
  — ошибка). Поэтому в `package.json` разрешено (`overrides`) ставить его с
  ESLint 10. Тот же приём для `openapi-typescript`, который объявляет
  TypeScript 5, а работает с 6.
- **TanStack Table 9** — новая мажорная версия, API отличается от 8.

## Последствия

- Новый экран-список — это колонки + `DataTable`; новая форма — `useAppForm`
  и поля из `src/components/form`. Другие способы запрещает линтер или ревью.
- Изменение API TradeNet: `npm run api`, затем `npm run typecheck` показывает
  всё, что нужно поправить, включая непереведённые коды ошибок.
- Переход на TypeScript 7 — отдельная задача, когда его поддержат
  typescript-eslint и openapi-typescript.
